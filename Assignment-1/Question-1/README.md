
# Assignment 1 - Question 1

## Project Title
Poshtik Campus - Food Ordering Website

## Objective
To design a responsive multi-page food ordering website using HTML5 and external CSS3.

## Requirements
1. Create a wireframe using Framer or another wireframing tool.
2. Develop at least 8 webpages:
   - Home / Menu Listing
   - Item Detail
   - Cart Summary
   - Order Form
   - Order Confirmation
   - Delivery Address
   - About Us
   - Contact Us
3. Use HTML5 and external CSS3.
4. Apply the CSS box model and media queries.
5. Make the website responsive for mobile, tablet, and desktop screens.

## Technologies Used
- HTML5
- CSS3
