# Assignment 1 — Question 1 (4 marks)

Poshtik Campus food-ordering website, designed using **only HTML5 and external CSS3**, no JavaScript or frameworks.

## Pages
1. `index.html` — Home / Menu listing
2. `item-detail.html` — Item Detail
3. `cart.html` — Cart Summary
4. `order.html` — Order Form
5. `confirmation.html` — Order Confirmation
6. `delivery.html` — Delivery Address
7. `about.html` — About Us
8. `contact.html` — Contact Us

## Design and responsive features
- `style.css` covers box model, CSS Grid/Flexbox and media queries for desktop, tablet and mobile.
- `wireframes/website-wireframe.svg` is a static design sketch; **it was not created in Framer**. Recreate/import it using a wireframing tool if your teacher requires evidence of using a tool.
- `images/` provides six local dish illustrations (no internet needed).
- **Before submitting:** open pages in browser and capture working website screenshots to a `screenshots/` folder.

## Run
Open `index.html` in a browser. All links are relative and work without a server.

**Scope:** Static front-end demo only, as required by the ban on JavaScript. Cart/checkout displays examples; forms cannot save or transmit actual orders.

## Food photographs
Uses real food photographs from Wikimedia Commons (attributions in PHOTO_CREDITS.md). Internet access is required for the images to load.
