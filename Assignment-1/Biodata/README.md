# Assignment 1 - Biodata

## Project Title

Personal Biodata - About Me Webpage

## Objective

To design a personal biodata webpage using HTML5 and external CSS3, presenting personal, educational, and technical information.

## Requirements

1. Create an individual About Me (Biodata) webpage.
2. Display personal details, including name and photograph.
3. Include a short personal introduction.
4. Display educational qualifications and academic details.
5. List technical skills and hobbies.
6. Provide contact information.
7. Apply appropriate CSS3 styling.
8. Make the webpage responsive for different screen sizes.

## Technologies Used

- HTML5
- CSS3
- CSS Flexbox
- CSS Media Queries
