# Assignment 2 - Questions 1 and 2

## Project Title
Mobile Recharge Plan Picker (React)

## Objective
Create a mobile recharge plan picker using React functional components, JSX, props, state, events and lists.

## Question 1 Requirements
1. Store four plans in an array: Daily 1.5 GB (₹299, 28 days), Daily 2 GB (₹349, 28 days), Annual (₹2999, 365 days) and Add-on 10 GB (₹99, 7 days).
2. Create a reusable `PlanCard` component which receives each plan through props.
3. Show all cards using `.map()` with a unique `key`.
4. Keep the selected plan in state and display its name and price below the cards.

## Question 2 Requirements
1. Display a thicker blue border around the selected plan card.
2. Change its button text from `Select` to `Selected`.

## Technologies Used
- React functional components
- JSX, props, `useState`, click events, array `.map()` and keys
- CSS3
- Vite (development/build tooling)

## How to Run
1. Open this folder in VS Code.
2. Run `npm install` followed by `npm run dev`.
3. Open the local URL printed by Vite.
