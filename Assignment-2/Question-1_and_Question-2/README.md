# Assignment 2 - Question 1 and Question 2

## Project Title

Mobile Recharge Plan Picker - React Application

## Objective

To develop an interactive mobile recharge plan selection application using React, reusable components, props, state, and event handling.

## Requirements

### Question 1

1. Store four recharge plans in a JavaScript array.
2. Create a reusable `PlanCard` component using props.
3. Display recharge plans using the `.map()` function with unique keys.
4. Provide a Select button for each recharge plan.
5. Use React `useState` to manage the selected plan.
6. Display the selected plan's name and price below the cards.

### Question 2

1. Highlight the selected recharge plan with a thicker blue border.
2. Change the button text from Select to Selected.
3. Ensure only the currently selected plan is highlighted.

## Technologies Used

- React.js
- JavaScript (JSX)
- HTML5
- CSS3
- Vite

## How to Run

1. Open the project folder in VS Code.
2. Open the terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the localhost URL displayed in the terminal.
